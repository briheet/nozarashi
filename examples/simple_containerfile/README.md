# Simple Containerfile

A minimal Python service built from a `Containerfile`. The container prints
`Hello from Nozarashi!` and exits.

```sh
sudo ../../bin/nozarashi create
../../bin/nozarashi build
../../bin/nozarashi up
../../bin/nozarashi logs hello
../../bin/nozarashi inspect hello
../../bin/nozarashi destroy
```
